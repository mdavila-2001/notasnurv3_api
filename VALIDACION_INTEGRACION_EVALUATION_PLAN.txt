package com.universidad_nur.notasnurv3_api.controllers;

import com.universidad_nur.notasnurv3_api.dto.ApiResponse;
import com.universidad_nur.notasnurv3_api.dto.EvaluationPlanResponse;
import com.universidad_nur.notasnurv3_api.services.EvaluationPlanService;
import lombok.RequiredArgsConstructor;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.security.access.prepost.PreAuthorize;
import org.springframework.security.core.Authentication;
import org.springframework.web.bind.annotation.*;

@RestController
@RequestMapping("/api/evaluation-plans")
@RequiredArgsConstructor
@CrossOrigin(origins = "*")
public class EvaluationPlanController {

    private final EvaluationPlanService evaluationPlanService;

    @GetMapping("/subject/{subjectId}")
    @PreAuthorize("hasAuthority(T(com.universidad_nur.notasnurv3_api.config.SecurityAuthorities).ROLE_TEACHER)")
    public ResponseEntity<ApiResponse<EvaluationPlanResponse>> getBySubject(
            @PathVariable Integer subjectId,
            Authentication authentication
    ) {
        EvaluationPlanResponse response = evaluationPlanService.getBySubject(subjectId, authentication.getName());
        return ResponseEntity.ok(new ApiResponse<>(true, "Plan obtenido", response));
    }

    @PostMapping("/subject/{subjectId}")
    @PreAuthorize("hasAuthority(T(com.universidad_nur.notasnurv3_api.config.SecurityAuthorities).ROLE_TEACHER)")
    public ResponseEntity<ApiResponse<EvaluationPlanResponse>> createForSubject(
            @PathVariable Integer subjectId,
            Authentication authentication
    ) {
        EvaluationPlanResponse response = evaluationPlanService.createForSubject(subjectId, authentication.getName());
        return ResponseEntity.status(HttpStatus.CREATED)
                .body(new ApiResponse<>(true, "Plan creado exitosamente", response));
    }

    @PostMapping("/subject/{subjectId}/activate")
    @PreAuthorize("hasAuthority(T(com.universidad_nur.notasnurv3_api.config.SecurityAuthorities).ROLE_TEACHER)")
    public ResponseEntity<ApiResponse<Void>> activatePlan(
            @PathVariable Integer subjectId,
            Authentication authentication
    ) {
        evaluationPlanService.activatePlan(subjectId, authentication.getName());
        return ResponseEntity.ok(new ApiResponse<>(true, "Plan de evaluación activado exitosamente", null));
    }

}

  "message": "Plan creado exitosamente",
  "data": {

NOTAS:
    - Siempre devuelve 201 CREATED aunque retorne plan existente
    - Si plan ya tiene componentes, los devuelve
    - La operación es idempotente (seguro llamar múltiples veces)

4. REQUISITOS DE SEGURIDAD
================================================================================

JWT TOKEN:
    ✅ REQUERIDO en header "Authorization"
    ✅ Formato: "Authorization: Bearer <token>"
    ✅ Token dura 24 horas (86400000 milisegundos)
    ✅ Sin token → 401 Unauthorized

ROL ESPECÍFICO:
    ✅ REQUERIDO: ROLE_TEACHER
    ✅ Si es ADMIN o STUDENT → 403 Forbidden
    ✅ Validación hecha por @PreAuthorize

CSRF TOKEN:
    ❌ NO REQUERIDO (API REST stateless con JWT)
    ❌ CSRF deshabilitado en SecurityConfig.java
    ❌ No es necesario enviar X-CSRF-TOKEN

CORS:
    ✅ HABILITADO para localhost:4200 y 4201
    ✅ Métodos permitidos: GET, POST, PUT, DELETE, PATCH, OPTIONS
    ✅ Headers permitidos: * (todos)
    ✅ Credenciales: habilitadas

VALIDACIÓN ADICIONAL:
    ✅ El docente DEBE ser propietario de la materia
    ✅ Si no es propietario → 403 Forbidden
    ✅ Validación en EvaluationPlanService.validateSubjectAndTeacher()

7. RESPUESTA A TU PREGUNTA: ¿CUÁL ES EL FORMATO CORRECTO?
================================================================================

LA RESPUESTA CORRECTA ES:

✅ POST /api/evaluation-plans/subject/{subjectId}
   Con BODY VACÍO (sin contenido JSON)

LA RESPUESTA INCORRECTA ES:

❌ POST /api/evaluation-plans
   Con body { subjectId, name, weight }

EXPLICACIÓN:

En el código del controller:
    @PostMapping("/subject/{subjectId}")
    public ResponseEntity<ApiResponse<EvaluationPlanResponse>> createForSubject(
            @PathVariable Integer subjectId,
            Authentication authentication
    )

Observaciones:
    1. La anotación es @PostMapping("/subject/{subjectId}")
       → El subjectId va en la URL, NO en el body

    2. No hay @RequestBody
       → No espera JSON en el body

    3. El servicio NO recibe parámetros adicionales
       → No recibe name, weight, description, etc.

    4. El plan se crea vacío
       → Sin componentes inicialmente
       → Los componentes se agregan después por otro endpoint

CÓMO DEBE HACERSE EN TU FRONTEND:

✅ CORRECTO:
    const url = '/api/evaluation-plans/subject/5';
    const response = await fetch(url, {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${token}`,
        'Content-Type': 'application/json'
      }
      // NO enviar body
    });

❌ INCORRECTO:
    const url = '/api/evaluation-plans';
    const response = await fetch(url, {
      method: 'POST',
      headers: { ... },
      body: JSON.stringify({
        subjectId: 5,
        name: "Mi Plan",
        weight: 100
      })
    });

9. CHECKLIST PARA VALIDAR INTEGRACIÓN EN TU FRONTEND
================================================================================

Antes de intentar crear un plan, verifica:

□ Token JWT obtenido exitosamente
□ Token incluido en header Authorization: Bearer <token>
□ Usuario tiene rol ROLE_TEACHER (verificar en decodificación del JWT)
□ SubjectId es un número válido que existe en BD
□ Usuario es propietario de esa materia
□ URL exacta: /api/evaluation-plans/subject/{subjectId}
□ Método: POST
□ Body: VACÍO (no enviar JSON)
□ Content-Type: application/json
□ El backend está corriendo en http://localhost:8080
□ CORS está habilitado en tu origen (localhost:4200 o 4201)

Errores comunes:

❌ Enviar body JSON: { subjectId, name, weight }
   → El backend lo ignora, pero espera body vacío
   
❌ Usar endpoint /api/evaluation-plans sin /subject/{id}
   → 404 Not Found

❌ Usar GET en lugar de POST
   → 405 Method Not Allowed

❌ Olvidar el token JWT
   → 401 Unauthorized

❌ No ser dueño de la materia
   → 403 Forbidden con mensaje "No tienes permisos..."
